# 后端 API Review Index

本文档记录 `our_project/src/main/scala/riichinexus/microservices` 下各微服务的 API 边界和业务逻辑。当前 API 与前端按类名对齐：前端 `XxxAPI` 对应后端同名 API message，实际路由由 API 类名推导为 `/api/<lowercase api class name>`，不再维护手写 REST 路径表。

## 当前约定

- API 入口：每个后端 API 是一个独立 `*APIMessage.scala` 文件，继承 `APIMessage[T]` 或 `APIWithTokenMessage[T]`，业务动作在 `plan(context)` 中实现。
- DTO 位置：请求、查询、响应视图统一放在对应微服务的 `objects/apiTypes` 下；前端对应在 `front/src/objects/<service>/apiTypes`。
- 响应边界：response/object 应返回显式 View/Response DTO，不直接把 domain model 暴露给前端；`fromDomain(...)` 只作为 domain 到 DTO 的转换入口。
- 分页约定：列表类接口一般返回 `PagedResponse[T]`，使用 `limit/offset` 或查询对象过滤。
- 权限约定：需要身份的写操作通常接收 `operatorId`、`playerId` 或 token，并在 API 内检查角色、成员关系、俱乐部管理员、赛事管理员或超级管理员权限。
- 事件约定：会改变核心业务状态的操作通常写审计、发布 domain event，或刷新 dashboard/analytics 投影。

## auth

账号、登录态、游客会话和权限检查。

- `RegisterAuthAPIMessage`：注册账号并创建关联玩家身份；校验用户名/密码/昵称，哈希密码，创建玩家资料，返回登录成功视图和 token。
- `LoginAuthAPIMessage`：校验账号密码和玩家状态；认证通过后签发 token，返回用户显示名、角色标记和 token。
- `RestoreAuthSessionAPIMessage`：从 token 恢复已登录账号会话；解析 token、读取账号/玩家状态，返回当前认证会话视图。
- `LogoutAuthAPIMessage`：注销 token 对应会话；当前主要返回标准消息，作为前端清理本地登录态的后端确认点。
- `CurrentSessionAuthAPIMessage`：按 `playerId` 或 `guestSessionId` 解析当前主体；返回显式 `CurrentSessionView`，包含 principal、displayName、角色标记、player/guestSession 简要 DTO。
- `AuthCheckPermissionAPIMessage`：检查指定 principal 是否拥有某个权限；用于前端或服务端按权限码做轻量授权判断。
- `CreateGuestSessionAuthAPIMessage`：创建游客会话；规范 displayName、记录过期时间和权限上下文，返回 `GuestSessionResponse`。
- `GetGuestSessionAuthAPIMessage`：按游客会话 ID 查询单个游客会话；不存在时抛业务错误。
- `ListGuestSessionsAuthAPIMessage`：分页列出游客会话；支持按 active 状态、displayName 等条件过滤。
- `RevokeGuestSessionAuthAPIMessage`：撤销游客会话；记录撤销原因/时间并返回撤销后的会话 DTO。
- `UpgradeGuestSessionAuthAPIMessage`：把游客会话升级/绑定到注册玩家；校验游客会话和玩家状态，完成迁移后返回游客会话 DTO。

## player

玩家资料、当前玩家解析和玩家列表。

- `CreatePlayerAPIMessage`：创建玩家资料；校验输入、生成玩家 ID、初始化 rank/elo/status/roleFlags，返回 `PlayerProfileView`。
- `GetPlayerAPIMessage`：按 `playerId` 获取玩家公开/后台资料视图。
- `GetCurrentPlayerAPIMessage`：按登录用户或操作者标识解析当前玩家；用于登录后把 userId 映射到 playerId。
- `ListPlayersAPIMessage`：分页查询玩家；支持 status、club、关键词等条件，返回 `PagedResponse[PlayerProfileView]`。

## club

俱乐部资料、成员、申请、权限、荣誉、财务/积分池、俱乐部参赛邀请。

- `CreateClubAPIMessage`：创建俱乐部；校验创建者玩家状态，初始化成员/管理员/积分池/金库，并刷新俱乐部投影。
- `GetClubAPIMessage`：按俱乐部 ID 查询俱乐部 DTO；不存在或已解散时按业务规则处理。
- `ListClubsAPIMessage`：分页列出俱乐部；支持名称、状态、招募等条件，返回俱乐部 DTO 列表。
- `ListClubMembersAPIMessage`：分页列出俱乐部成员资料；读取 club 成员 ID 后映射为玩家资料视图。
- `AddClubMemberAPIMessage`：管理员直接添加成员；检查俱乐部有效、操作者权限和玩家状态，更新成员列表并刷新投影。
- `RemoveClubMemberAPIMessage`：移除俱乐部成员；校验操作者权限和成员关系，更新 club 并刷新投影。
- `AssignClubAdminAPIMessage`：授予俱乐部管理员；校验操作者权限、目标成员和俱乐部状态，更新 admins。
- `RevokeClubAdminAPIMessage`：撤销俱乐部管理员；校验权限和成员身份，更新 admins。
- `AssignClubTitleAPIMessage`：给成员设置内部称号；校验成员关系，写入成员特权/称号快照。
- `ClearClubTitleAPIMessage`：清除成员内部称号；保留成员其他权限和贡献信息。
- `ClubPrivilegeDefinitionsAPIMessage`：返回俱乐部权限定义；供前端展示可委派权限和说明。
- `GetClubMemberPrivilegeAPIMessage`：查询指定成员在俱乐部内的权限快照。
- `ListClubMemberPrivilegesAPIMessage`：分页列出俱乐部成员权限快照；支持按 playerId 过滤。
- `AdjustClubMemberContributionAPIMessage`：调整成员贡献值；校验管理员权限，更新成员贡献和衍生 rank/privilege。
- `AdjustClubTreasuryAPIMessage`：调整俱乐部金库余额；记录金额变更并返回更新后的俱乐部 DTO。
- `AdjustClubPointPoolAPIMessage`：调整俱乐部积分池；校验操作权限，更新 pointPool。
- `UpdateClubRankTreeAPIMessage`：更新俱乐部内部 rank tree；影响贡献到称号/权限的映射。
- `UpdateClubRecruitmentPolicyAPIMessage`：更新招募/申请政策；控制是否开放申请、申请要求和 SLA。
- `UpdateClubRelationAPIMessage`：维护俱乐部关系；设置联盟/竞争/中立关系并返回更新后的俱乐部。
- `AwardClubHonorAPIMessage`：授予俱乐部荣誉标题；校验权限后写入荣誉集合。
- `RevokeClubHonorAPIMessage`：撤销俱乐部荣誉标题；从荣誉集合中移除。
- `SubmitClubApplicationAPIMessage`：玩家或游客提交入会申请；检查招募策略、重复申请和申请人上下文，返回申请 DTO。
- `GetClubApplicationAPIMessage`：查询单个入会申请；根据操作者/申请人身份决定可见性和可操作标记。
- `GetCurrentClubApplicationAPIMessage`：查询当前 principal 对某俱乐部的申请状态；用于前端展示“已申请/可撤回/可再次申请”。
- `ListClubApplicationsAPIMessage`：俱乐部管理员分页查看申请箱；支持状态、申请人、分页过滤。
- `ReviewClubApplicationAPIMessage`：统一审核申请；根据 decision approve/reject/decline 等更新申请并返回申请视图。
- `ApproveClubApplicationAPIMessage`：批准入会申请并把玩家加入俱乐部；更新申请状态、成员列表和俱乐部投影。
- `RejectClubApplicationAPIMessage`：拒绝入会申请；写入审核人、审核时间和备注。
- `WithdrawClubApplicationAPIMessage`：申请人撤回入会申请；校验 principal 和申请状态后写入撤回信息。
- `ListClubTournamentsAPIMessage`：列出俱乐部相关赛事邀请/参赛记录；聚合 tournament 状态、阶段和俱乐部可执行动作。
- `AcceptClubTournamentAPIMessage`：接受俱乐部赛事邀请；校验俱乐部管理员权限，把俱乐部加入赛事参与方并返回赛事 mutation view。
- `DeclineClubTournamentAPIMessage`：拒绝俱乐部赛事邀请；校验权限并从邀请/参与状态中移除或标记拒绝。

## publicquery

公开查询读模型。面向游客和未登录前端页面，原则上不改变业务状态。

- `ListPublicSchedulesAPIMessage`：分页查询公开赛程；聚合赛事、阶段、牌桌数量、活跃桌和参与人数。
- `ListPublicTournamentsAPIMessage`：分页查询公开赛事列表；返回赛事摘要、状态、时间、阶段数和参与规模。
- `GetPublicTournamentAPIMessage`：查询公开赛事详情；聚合阶段规则、排名快照、淘汰赛 bracket 和公开参与信息。
- `ListPublicClubsAPIMessage`：分页查询公开俱乐部目录；返回成员规模、战力、积分、金库、荣誉和关系摘要。
- `GetPublicClubAPIMessage`：查询公开俱乐部详情；聚合申请政策、当前阵容、最近比赛、荣誉和关系。
- `PublicPlayerLeaderboardAPIMessage`：玩家排行榜；按 elo/rank 等维度排序，返回玩家排名条目。
- `PublicClubLeaderboardAPIMessage`：俱乐部排行榜；按 powerRating/points 等维度排序，返回俱乐部排名条目。

## dictionary

业务字典、namespace 治理、协作者和提醒流程。

- `DictionarySchemaAPIMessage`：返回全局字典 schema；供前端知道可用 namespace、字段和约束。
- `DictionaryGetEntryAPIMessage`：按 namespace/key 查询单个字典项；返回 `GlobalDictionaryEntryResponse`。
- `DictionaryListEntriesAPIMessage`：分页列出字典项；支持 namespace、关键词、状态等过滤。
- `DictionaryUpsertEntryAPIMessage`：新增或更新字典项；校验 namespace 权限和字段格式，写入 value/context/owner 信息。
- `DictionaryListNamespacesAPIMessage`：分页列出 namespace 注册记录；支持状态、owner、上下文等过滤。
- `DictionaryRequestNamespaceAPIMessage`：申请 namespace；校验申请人状态、上下文俱乐部成员关系和重复申请。
- `DictionaryReviewNamespaceAPIMessage`：审核 namespace 申请；批准或拒绝并写入 reviewer、reviewAt、reviewNote。
- `DictionaryRevokeNamespaceAPIMessage`：撤销 namespace；校验 owner/admin 权限，标记 namespace 不再可用。
- `DictionaryTransferNamespaceAPIMessage`：转移 namespace owner；校验当前 owner 和目标 owner 状态。
- `DictionaryUpdateNamespaceCollaboratorsAPIMessage`：更新 namespace 协作者；维护可共同编辑的玩家集合。
- `DictionaryUpdateNamespaceContextAPIMessage`：更新 namespace 上下文；例如绑定/调整俱乐部上下文和说明。
- `DictionaryNamespaceBacklogAPIMessage`：查询 namespace 治理 backlog；汇总待审核、待提醒、超时等任务。
- `DictionaryProcessNamespaceRemindersAPIMessage`：处理 namespace 提醒任务；按时间窗口生成/更新 reminder action。

## tournament

赛事核心：创建、发布、报名/白名单、阶段规则、排桌、牌桌状态、牌谱、记录、结算、晋级。

- `TournamentCreateAPIMessage`：创建赛事；校验组织者、时间、初始管理员和基础配置，返回赛事摘要。
- `TournamentGetAPIMessage`：查询赛事运营详情；聚合参赛俱乐部、参赛玩家、白名单、阶段和阵容提交。
- `TournamentListAPIMessage`：分页查询赛事摘要；支持状态、时间、管理员等条件。
- `TournamentPublishAPIMessage`：发布赛事；校验赛事管理员权限，把赛事从草稿推进到公开/可报名状态，并返回 mutation view。
- `TournamentStartAPIMessage`：开始赛事；校验状态和管理员权限，推进赛事状态并返回摘要。
- `TournamentAssignAdminAPIMessage`：为赛事添加管理员；校验操作者权限和目标玩家状态。
- `TournamentRevokeAdminAPIMessage`：撤销赛事管理员；更新 admins 并返回赛事摘要。
- `TournamentRegisterPlayerAPIMessage`：玩家报名赛事；校验赛事状态、白名单、重复报名和玩家状态。
- `TournamentRegisterClubAPIMessage`：俱乐部报名赛事；校验俱乐部状态、管理员权限、白名单和重复参赛。
- `TournamentRemoveClubParticipationAPIMessage`：移除俱乐部参赛资格；更新赛事参与方并返回 mutation view。
- `TournamentWhitelistPlayerAPIMessage`：把玩家加入赛事白名单；用于受邀或限制报名赛事。
- `TournamentWhitelistClubAPIMessage`：把俱乐部加入赛事白名单；用于俱乐部制赛事邀请。
- `TournamentWhitelistListAPIMessage`：分页查询赛事白名单条目；区分玩家/俱乐部参与类型。
- `TournamentStageCreateAPIMessage`：创建赛事阶段；配置阶段名称、赛制、轮数和排序。
- `TournamentStageDirectoryAPIMessage`：返回赛事阶段目录；用于运营页快速切换阶段和查看状态。
- `TournamentStageConfigureRulesAPIMessage`：配置阶段规则；更新晋级规则、瑞士轮规则或淘汰赛规则。
- `TournamentStageScheduleTablesAPIMessage`：为阶段生成/调度牌桌；调用排桌服务，写入 pending/scheduled tables，返回 mutation view。
- `TournamentStageTablesAPIMessage`：分页/过滤查询某阶段牌桌；返回 `TournamentTableView` 列表。
- `TournamentStageStandingsAPIMessage`：查询阶段排名快照；聚合比赛记录和积分/排名规则。
- `TournamentStageKnockoutBracketAPIMessage`：查询淘汰赛 bracket；返回对阵轮次、槽位、胜者和状态。
- `TournamentStageAdvancementPreviewAPIMessage`：预览阶段晋级结果；不落库，仅根据当前排名和规则计算候选晋级名单。
- `TournamentStageAdvanceAPIMessage`：执行阶段晋级；把晋级玩家/俱乐部推进到下一阶段或后续赛程。
- `TournamentStageCompleteAPIMessage`：完成阶段；校验阶段状态和结果，生成完成后的晋级/排名快照。
- `TournamentStageSubmitLineupAPIMessage`：俱乐部提交阶段阵容；校验俱乐部参赛、成员资格、active/reserve 人数和提交权限。
- `TournamentTableListAPIMessage`：分页查询赛事牌桌；可按 tournament/stage/status/player 等过滤。
- `TournamentTableGetAPIMessage`：查询单张牌桌详情；返回座位、状态、ready、牌谱/记录关联信息。
- `TournamentTableStartAPIMessage`：开始牌桌；校验操作者权限、座位状态和桌状态。
- `TournamentTableResetAPIMessage`：强制重置牌桌；管理员操作，清理/恢复座位和桌状态。
- `TournamentTableUpdateSeatStateAPIMessage`：更新指定座位状态；例如落座、离桌、ready、违规状态等。
- `TournamentTableUpdateOwnReadyAPIMessage`：玩家更新自己在桌上的 ready 状态；校验玩家属于该桌座位。
- `TournamentTableUploadPaifuAPIMessage`：上传牌谱并绑定牌桌；校验牌谱与桌座位/玩家匹配，可能生成比赛记录。
- `TournamentPaifuListAPIMessage`：分页查询赛事牌谱摘要；可按 tournament、table、player 过滤。
- `TournamentPaifuGetAPIMessage`：查询单份牌谱详情/摘要；用于回放页面或运营检查。
- `TournamentRecordListAPIMessage`：分页查询比赛记录；支持赛事、阶段、桌、玩家过滤。
- `TournamentRecordGetAPIMessage`：按记录 ID 查询比赛记录。
- `TournamentRecordGetByTableAPIMessage`：按 tableId 查询该桌对应比赛记录。
- `TournamentSettleAPIMessage`：生成赛事/阶段结算；根据排名、奖池、手续费、俱乐部分成和调整项生成 settlement snapshot。
- `TournamentSettlementListAPIMessage`：分页查询结算快照；支持状态、阶段、revision 等条件。
- `TournamentSettlementGetAPIMessage`：按 settlementId 或 tournament/stage 查询结算详情。
- `TournamentSettlementFinalizeAPIMessage`：确认结算；把 draft settlement 标记为 finalized，并发布/记录结算完成事件。

## tournament/appeal

赛事牌桌申诉子域，处理申诉创建、查询、分派、裁决和重开。

- `AppealFileAPIMessage`：提交牌桌申诉；记录申诉人、描述、附件、优先级和 dueAt，返回申诉票据。
- `AppealListAPIMessage`：分页查询申诉；支持 tournament、stage、table、status、priority、assignee 等过滤。
- `AppealGetAPIMessage`：按 appealId 查询申诉详情。
- `AppealResolveAPIMessage`：处理申诉为 resolved/rejected 等结果；写入处理人、结论和日志。
- `AppealAdjudicateAPIMessage`：裁决申诉；写入裁决类型、verdict、tableResolution，并可能影响牌桌后续处理。
- `AppealReopenAPIMessage`：重开已结束申诉；记录重开原因、操作者和 reopenCount。
- `AppealUpdateWorkflowAPIMessage`：更新申诉工作流字段；分派 assignee、调整 priority/dueAt、清空分派或补充 note。

## platformadmin

平台级超级管理员操作，权限高、影响范围大。

- `PlatformAdminBanPlayerAPIMessage`：封禁玩家；校验超级管理员权限，更新玩家状态并发布/记录封禁事件。
- `PlatformAdminDissolveClubAPIMessage`：解散俱乐部；校验超级管理员权限，标记 dissolvedAt 并发布/记录解散事件。
- `PlatformAdminGrantSuperAdminAPIMessage`：授予玩家超级管理员角色；校验操作者权限，更新玩家 role flags。

## opsanalytics

运营分析、投影 dashboard、审计、事件 outbox、事件级联和高级统计任务。

- `OpsAnalyticsPlayerDashboardAPIMessage`：查询玩家 dashboard 投影；返回玩家运营摘要、指标和最近动态。
- `OpsAnalyticsClubDashboardAPIMessage`：查询俱乐部 dashboard 投影；返回俱乐部成员、战力、积分、活跃度等摘要。
- `OpsAnalyticsPlayerAdvancedStatsAPIMessage`：查询玩家高级统计面板；读取统计任务/投影结果。
- `OpsAnalyticsClubAdvancedStatsAPIMessage`：查询俱乐部高级统计面板；聚合俱乐部成员和比赛统计。
- `OpsAnalyticsAdvancedStatsSummaryAPIMessage`：查询高级统计任务队列摘要；返回待处理、完成、失败等数量。
- `OpsAnalyticsListAdvancedStatsTasksAPIMessage`：分页查询高级统计任务；支持状态、目标类型、时间窗口过滤。
- `OpsAnalyticsRecomputeAdvancedStatsAPIMessage`：提交高级统计重算任务；按目标玩家/俱乐部/赛事和原因创建任务。
- `OpsAnalyticsProcessAdvancedStatsAPIMessage`：处理高级统计任务；批量执行待处理任务并返回处理结果。
- `OpsAnalyticsPerformanceSummaryAPIMessage`：返回性能诊断摘要；汇总状态计数、指标和诊断时间。
- `OpsAnalyticsListAuditsAPIMessage`：分页查询审计日志；按 actor、eventType、aggregate、时间过滤。
- `OpsAnalyticsListAggregateAuditsAPIMessage`：分页查询某 aggregate 的审计日志；用于追踪单个业务对象历史。
- `OpsAnalyticsDomainEventsSummaryAPIMessage`：查询 domain event bus/outbox 摘要；展示事件发送、积压和失败情况。
- `OpsAnalyticsListDomainEventOutboxAPIMessage`：分页查询 domain event outbox 记录；支持 status、eventType、consumer、时间过滤。
- `OpsAnalyticsDomainEventOutboxHistoryAPIMessage`：查询单条 outbox 记录的投递历史；包含 delivery receipts。
- `OpsAnalyticsAcknowledgeDomainEventOutboxAPIMessage`：批量确认 outbox 记录；把符合条件的记录标记为 acknowledged。
- `OpsAnalyticsAcknowledgeDomainEventOutboxRecordAPIMessage`：确认单条 outbox 记录；记录确认时间和操作者上下文。
- `OpsAnalyticsQuarantineDomainEventOutboxAPIMessage`：批量隔离 outbox 记录；写入隔离原因，避免继续投递。
- `OpsAnalyticsQuarantineDomainEventOutboxRecordAPIMessage`：隔离单条 outbox 记录；用于人工处理异常事件。
- `OpsAnalyticsReplayDomainEventOutboxAPIMessage`：批量重放 outbox 记录；把记录重新投入投递流程并返回批量结果。
- `OpsAnalyticsReplayDomainEventOutboxRecordAPIMessage`：重放单条 outbox 记录；用于修复单个失败事件。
- `OpsAnalyticsListDomainEventSubscribersAPIMessage`：分页查询 domain event subscriber 状态；展示订阅者、消费状态和 lag。
- `OpsAnalyticsListDomainEventSubscriberPartitionsAPIMessage`：分页查询 subscriber partition 状态；细化到分区/消费者进度。
- `OpsAnalyticsListEventCascadeRecordsAPIMessage`：分页查询事件级联记录；追踪事件触发的投影、结算、统计或通知链路。

## shared / infrastructure

`shared` 和基础设施不是业务微服务，主要提供 API message 注册、`PagedResponse`、JSON codec、OpenAPI/文档模型、token API 支撑、权限/上下文辅助等公共能力。业务 API 不应把 shared 当作领域边界；它只承载跨微服务复用的技术结构。
